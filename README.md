# Vowel Snake

A JavaFX snake game where the snake eats vowels (A, E, I, O, U) and must avoid consonants.

## Rules
- Eat a vowel: +10 points and the snake grows
- Eat a consonant, hit a wall, or hit yourself: game over

## Controls
Arrow keys or WASD to move, SPACE to pause, R to restart.

## Run
Requires JDK 17+ and Maven.

    mvn javafx:run
